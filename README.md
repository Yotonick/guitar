# Guitar — мини-апп для гитаристов

Тюнер с микрофона, табы с проигрыванием (в том числе из Songsterr), генератор рифов. Тёмный, под телефон, открывается в Telegram Mini App.

## Что внутри

- `index.html`, `css/`, `js/` — сам сайт (статика, подходит для GitHub Pages)
- `vendor/alphatab/` — плеер табов alphaTab (лежит локально, интернет для него не нужен)
- `worker/worker.js` — прокси к Songsterr для Cloudflare Workers (бесплатно)
- `config.js` — сюда можно вписать адрес воркера

## Запуск сайта

1. Создайте репозиторий на GitHub, залейте всё содержимое папки (кроме `worker/`, её можно тоже).
2. Settings → Pages → Deploy from branch → `main` / root.
3. Сайт откроется по `https://ваш-ник.github.io/репозиторий/`. Микрофон работает только по https, GitHub Pages подходит.

## Подключение Songsterr (без него работают тюнер, генератор и свои файлы)

Songsterr не отдаёт данные браузеру напрямую (CORS), поэтому нужен маленький прокси:

1. Зарегистрируйтесь на cloudflare.com (бесплатно).
2. Workers & Pages → Create → Create Worker → вставьте код из `worker/worker.js` → Deploy.
3. Скопируйте адрес вида `https://xxx.workers.dev`.
4. В приложении: «Песни» → шестерёнка → вставьте адрес. Либо впишите его в `config.js`.

Проверка: откройте `адрес/search?q=metallica` — должен показаться список песен в JSON.

Важно: у Songsterr нет официального API, прокси использует те же адреса, что и их сайт. Если они что-то поменяют, поиск или загрузка могут перестать работать, и тогда править нужно только `worker.js`.

## Как пользоваться

- **Тюнер**: «Слушать», играйте струну. Стрелка и подсказка «Подтяни / Ослабь». Нажмите на струну, чтобы строить только её. Строй (Drop C, 7 струн, свой) выбирается вверху. По нажатию на частоту меняется камертон A4.
- **Песни**: поиск, избранное (сердечко в плеере), недавние, открытие своего `.gp/.gp5/.gpx` файла.
- **Плеер**: скорость 40–100%, метроном, отсчёт, цикл (нажмите значок цикла, потом первый и последний такт), «Табы / Ноты+табы», дорожки (громкость, M — заглушить, S — соло).
- **Рифф**: выберите жанр, нажмите «Сгенерировать». Рифф играется с барабанами, 🎲 в плеере даёт новый вариант.
