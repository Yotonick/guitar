# Гитарное приложение: состояние проекта (на 10 ноября 2026)

Для продолжения работы в новом чате: подключи папку `D:\CLAUDE\guitar` и попроси прочитать этот файл.

## Что это
Мобильный сайт для электрогитаристов, делается для себя. Позже станет Telegram Mini App, а пока живёт на GitHub Pages (репозиторий `Yotonick/guitar`). Платить за сервисы не хочу, юридические риски с Songsterr меня не волнуют, качество важнее всего.

Как выкладывать:
```
cd D:\CLAUDE\guitar
git add .
git commit -m "..."
git push
```
После деплоя нажать Ctrl+F5 (иначе браузер держит старый кэш).

**Деплой:** свой workflow `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions). Ждёт GitHub до 30 минут вместо стандартных 10: в ноябре 2026 у GitHub Pages были массовые зависания `syncing_files`. На сайт уходят только `index.html, config.js, css, js, fonts, vendor`. Папка `_src/` в `.gitignore` (для исходных записей звуков).
**Если деплой висит на `syncing_files`:** отменить запуск, удалить окружение (Settings → Environments → github-pages → Delete) и запустить заново (Actions → Deploy site → Run workflow). Окружение создаётся само. Помогло 10.11.

Проверить сайт без деплоя: `python -m http.server 8000` в папке и открыть http://localhost:8000 (микрофон и усилитель работают только на localhost или https).

## Что уже сделано
- **Тюнер.** Работает с микрофона по алгоритму YIN. Режимы «по струнам» и «хроматический», строи на выбор, свой строй, калибровка A4. Шкала в двух вариантах (линейка или дуга), переключается кнопкой. Если нажать на струну, тюнер ловит только её.
- **Песни.** Поиск по Songsterr через бесплатный воркер Cloudflare (`worker/worker.js`; адрес вставляется в настройках вкладки «Песни»). Воркер отдаёт ноты дорожек в JSON, а `js/songsterr.js` переводит их в alphaTex. Есть «Избранное / Недавние» и открытие своих файлов Guitar Pro.
- **Плеер (alphaTab 1.9, в `vendor/`).** Табы, курсор, скорость 40–100%, цикл по тактам, метроном, отсчёт, вид «табы / ноты+табы».
  - **Дорожки:** режимы «Фокус / Поровну / Минус-один», громкость каждой дорожки, M/S, выбор, какую дорожку показывать.
  - **Звук:** гитарный усилитель (Дисторшн / Овердрайв / Чистый, ручки Драйв, Низ, Середина, Верх) и выбор набора звуков.
- **Звук (обновлено 10.11).** Набор «Гитара + усилитель» = MuseScore General + два набора поверх:
  - `EGuitar_Live.sf3` (2,6 МБ): Fender из FreePats FSBS direct (CC0). Сырой сигнал на программах 28–31 идёт в живой усилитель (`js/amp.js`). Тот же Fender, запечённый через чистый усилитель с лёгкой компрессией, стоит на программах 26–27 (чистые гитары, идут мимо усилителя). Два слоя силы удара: до 85 тихий, это призрачные ноты и легато (alphaTab: обычная нота = 95, призрачная/hammer = 79, акцент = 111, сильный = 127). Соседние полутона используют разные дубли записи. Затухание после отпускания: 0,25 с для дисторшна, 0,45 с для чистой.
  - `Drums_Live.sf3` (1 МБ): живая установка MuldjordKit (Lars Muldjord, CC-BY 4.0, лицензия рядом). Раскладка GM в банке 128, 5 слоёв силы удара у бочки, малого и хэтов, 3 слоя у остальных. Хэты глушат друг друга, хвосты не обрываются при отпускании.
  - Гейт в усилителе смягчён (раньше обрывал каждую ноту): порог закрытия 0,0008, удержание 80 мс, плавное затухание.
  - В формате SF2 нет случайного чередования дублей одной ноты, поэтому повтор одного и того же звука идентичен. Разнообразие дают слои силы удара и разные дубли на соседних нотах.
  - Гитары синтезатор отдаёт в левый канал, всё остальное в правый, усилитель обрабатывает только левый. alphaTab отдаёт один стереовыход, по дорожкам звук не разделить.
  - Пересобрать звуки: `tools/build_gtr.py <папка FSBS direct> <выход.sf3>` и `tools/build_drums.py <папка MuldjordKit> <выход.sf3>` (нужны numpy, scipy, soundfile, ffmpeg с libvorbis). Архивы-исходники лежат в корне проекта и исключены в `.gitignore`.
- **Ударные из Songsterr.** Расширенные номера Guitar Pro (91 = малый римшот, 92 = полуоткрытый хэт и т. д.) переводятся в GM (`gmDrum` в `js/songsterr.js`, таблица из alphaTab). Раньше эти удары пропадали. Призрачные удары передаются как `{g}`, акценты как `{ac}`/`{hac}`.
- **Автоподбор усилителя под песню.** Смотрит, какая гитара указана в табе (дисторшн, овердрайв, чистая), и на строй. Если подкрутить ручки, настройки сохраняются для этой песни, есть кнопка «Вернуть авто».
- **ИИ-генератор риффов (`js/riffai.js`, новое 10.11).** Учится прямо в браузере на табах Songsterr:
  - Стиль: 7 кнопок или своё поле («грув», «пост-хардкор», «Deftones, Tool»). Список стилей и групп-образцов в `STYLES`, всего 18 стилей с русскими и английскими названиями. Если введены не жанр, а группы, учится на их песнях.
  - Обучение: через воркер скачивает около 22 песен (по 2–8 на группу), берёт перегруженные гитары, бас и барабаны. Модель хранит: ритмические рисунки тактов (сетка 1/16, только 4/4), цепь Маркова 2-го порядка по нотам относительно тоники (с откатом на 1-й и 0-й порядок, учитывает длину ноты и глушение), частоты приёмов (слайд, бенд, вибрато, стаккато, мёртвые ноты), барабанные грувы и сбивки, насколько бочка повторяет гитару, темпы, строи. Модель весит около 40 КБ и хранится в localStorage (`riffai:<стиль>`, до 12 стилей).
  - Генерация: фраза A A' A B (8 тактов: A A' A B A A' A C), аппликатура с учётом позиции руки (растяжка не больше 4 ладов, низкие струны), бас в унисон октавой ниже, барабаны из выученных грувов.
  - В плеере кнопки «Вариация» (развивает тот же рифф) и «Ещё рифф».
  - Старый генератор (`js/riff.js`) остался: переключатель «ИИ / Простой». Если воркера нет, работает простой.
  - Проверено: 1200 риффов и вариаций разобраны alphaTab без ошибок, все такты ровно 4/4. Музыкальность проверялась на 16 настоящих песнях (Korn, Slipknot, Metallica, Slayer, AC/DC и другие).
- **Дизайн.** Фон тёмного дерева грифа, светлый «костяной» текст, янтарный акцент. Шрифты Fira Sans Extra Condensed и Golos лежат локально в `fonts/`. Нижнее меню нарисовано как лады грифа.
- **Исправлено 10.11:** курсор табов мигал вместо плавного движения. Курсор исключён из правила `prefers-reduced-motion`, у него убраны скругление и тень: alphaTab растягивает однопиксельный элемент через `scale`, и на телефонах это мерцает. Если мигание останется, проверить, где именно (телефон, Telegram, ПК).
- **Исправлено 10.11:** барабаны в ИИ-риффах были «не в такт». Генератор теперь берёт дорожку настоящего барабанщика (по количеству бочки и малого), понимает расширенные номера GP и призрачные удары, берёт только ровные грувы (малый на 2 и 4, хаф-тайм или скэнк), а A и B играются грувами из одной песни. Версия модели 2: старые модели переучиваются сами.

## Известные проблемы
- **Звук.** 10.11 сделан большой апгрейд (см. выше), на слух ещё не проверен. Сравнения «было/стало» записаны в mp3.
- **Ненужные файлы.** `vendor/alphatab/soundfont/sonivox.sf2`, `EGuitar_Amp.sf3` и `EGuitar_DI.sf3` больше не используются, их можно удалить (около 3,5 МБ). `GeneralUser-GS.sf2` (32 МБ) используется как «запасной набор» в меню звука.
- **Загрузка файлов в папку.** Иногда загрузка файлов в папку отчитывается об успехе, а файл остаётся старым. Поэтому после загрузки нужно сверять размеры.

## Карта файлов
- `index.html`, `css/style.css`: разметка и стили.
- `js/app.js`: вся логика интерфейса (тюнер, песни, плеер, микшер, звук, рифф).
- `js/riffai.js`: ИИ-генератор (стили, сбор песен, обучение, генерация, вариации, аппликатура, alphaTex).
- `js/riff.js`: простой генератор риффов (запасной).
- `js/amp.js`: усилитель в реальном времени.
- `js/tuner.js`, `js/tunings.js`: определение высоты звука и строи.
- `js/songsterr.js`: перевод Songsterr JSON в alphaTex.
- `js/data.js`: хранение (избранное, история, адрес воркера).
- `worker/worker.js`: прокси Cloudflare к Songsterr (загружается вручную в панели Cloudflare).
- `tools/`: скрипты на Python, которыми собраны гитарные саундфонты.
- `.github/workflows/pages.yml`: деплой на GitHub Pages.
